# Documentation research workspace

This folder is reserved for preserved non-production research material such as
draft GeoJSON, KML/KMZ, coordinate investigations, map-provider captures,
tracing notes, research exports, and temporary analyses that retain evidential
value.

Research files are not production source data and must not be consumed by the
application or its generators without a separate review and explicit approval.
Current placement rules are defined in [docs/README.md](../README.md).

The
[Cambridgeshire Local Heritage List research guide](./cambridgeshire-local-heritage-list-skill.md)
is retained here as reusable external-reference guidance. It is not controlling
project policy.
