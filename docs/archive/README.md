# Documentation Archive

This folder contains archived Markdown documentation for Alex's Photo Board.

Archived docs are historical evidence and working records. They are not current instructions by default.

Current documentation lives in:

- [../README.md](../README.md)

Important notes:

- old phase docs may contain outdated “next phase” recommendations;
- archived planning or worksheet docs must not override newer current-state, verification, release, or rules documents;
- do not delete archived docs without owner approval;
- prefer keeping historical evidence unless there is a clear approved reason to remove it.

Archive subfolders currently include:

- `phase-records/` for archived completion notes and older milestone records;
- `phase-9/`, `phase-10/`, and `phase-11a/` for older phase materials;
- `phase-12-design/` for older design-history records;
- `old-roadmaps/` for superseded roadmap material;
- `reference-experiments/` for archived inspiration/reference notes.
