# Admin Review and Promotion Workflow

Use this workflow when work touches nomination review, admin assessment, or promotion into public place data.

## Checks

1. Signed-in user can submit a nomination.
2. Owner can see it in My nominations.
3. Non-owner cannot read it.
4. Admin can read it.
5. Admin can update review status.
6. Admin notes stay private.
7. Approved nomination can be promoted.
8. Promoted place appears in `communityPlaces`.
9. Public place page shows only approved public fields.
10. Public export does not include private nomination or admin data.
11. Original nomination remains owner/admin only.

## Alex's Photo Board Notes

- Promotion is not just a status change; it is a privacy boundary.
- A successful admin workflow must not turn nomination-review evidence into public export content by accident.
